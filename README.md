# Table Tennis Tournament Manager

A web app for running table tennis tournaments at clubs and university teams.

Organizers manage players and matches from a laptop. Scorekeepers enter results from their phones.

**Status:** Planning stage. This repository contains the requirements and build plan. There is no working app or demo yet.

## Planned features

- Register players and check them in.
- Track entry fees collected in cash or by card.
- Create groups and calculate standings.
- Generate knockout brackets and advance winners.
- Enter match scores from a laptop or phone.
- Save player results and ratings for future tournaments.

The first version will support singles tournaments with a group stage followed by knockout matches. It is designed for small events with around 20 players and a few tables.

Players will not need accounts. Entry fees will be recorded manually; the app will not process payments.
